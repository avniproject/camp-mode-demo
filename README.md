# Avni Camp Mode demo

An interactive page that shows Avni's Camp mode: a registration desk, a nurse and a doctor share one patient across three phones in a village with no internet.

Live at https://camp.avniproject.org

Everything is in `index.html`, with no build step. Open it in a browser to try it locally. A link ending in `#step-7` opens the page at that step.

All people, phones and network details in the demo are made up. The screen wording follows the Avni 18.3 app.
